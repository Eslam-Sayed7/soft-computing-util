Soft Computing Utilities Library

This library provides comprehensive implementations of soft computing techniques including genetic algorithms, fuzzy logic systems, and neural networks.

Genetic Algorithms Package

The softcomputing.genetic package provides a flexible and extensible framework for implementing genetic algorithms. It supports various chromosome representations and genetic operators.

Key Features

  • Multiple Chromosome Types: Binary, Integer, and Floating-Point representations
  • Flexible Selection Strategies: Tournament, Roulette Wheel, Rank, and Random selection
  • Various Crossover Methods: Single-Point, Two-Point, and Uniform crossover
  • Mutation Operators: Type-specific mutation strategies
  • Replacement Strategies: Elitism, Full Generation, and Steady-State replacement
  • Builder Pattern: Easy configuration through fluent API

Quick Start Example

// Create a genetic algorithm to solve an optimization problem
GeneticAlgorithm<BinaryChromosome> ga = new GeneticAlgorithmBuilder<BinaryChromosome>()
    .withChromosomeFactory(new BinaryChromosomeFactory())
    .withPopulationSize(100)
    .withGeneLength(20)
    .withMaxGenerations(1000)
    .withMutationRate(0.01)
    .withCrossoverRate(0.7)
    .withSelectionStrategy(new TournamentSelection<>(5))
    .withCrossoverStrategy(new SinglePointCrossover<>())
    .withMutationStrategy(new BinaryMutation(0.01))
    .withReplacementStrategy(new ElitismReplacement<>(10))
    .withFitnessFunction(chromosome -> evaluateFitness(chromosome))
    .withPopulation()  // generates initial population
    .build();

// Run the algorithm
ga.run();

Package Structure

  • softcomputing.genetic.core - Main algorithm classes
  • softcomputing.genetic.chromosome - Chromosome representations
  • softcomputing.genetic.operators - Genetic operators
    • selection - Parent selection strategies
    • crossover - Crossover/recombination strategies
    • mutation - Mutation strategies
    • replacement - Population replacement strategies
  • softcomputing.genetic.utils - Utility classes

Getting Started

To use this library, add it to your Maven or Gradle project and explore the packages. Start with the GeneticAlgorithmBuilder class in the core package.
